## Sistemas Operativos

- **Shell:** Interfaz de usuario que permite a los usuarios realizar tareas. (CLI/GUI)
	- *CLI:* Interfaz de Línea de Comandos
	- *GUI:* Interfaz Gráfica de Usuario
- **Kernel:** Administra los recursos del hardware para cumplir requisitos del software.
- **Hardware:** Parte física de un dispositivo.
## Métodos de Acceso

- **Consola:** Conexión física directa.
- **SSH(Secure Shell):** Conexión CLI remota segura a través de una interfaz virtual
- **Telnet:** Conexión CLI remota insegura a través de una interfaz virtual.
- **Auxiliar:** Conexión remota mediante módem telefónico.
