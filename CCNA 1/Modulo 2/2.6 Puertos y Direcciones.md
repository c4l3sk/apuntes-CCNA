## Direcciones IP

- Permite que los dispositivos se ubiquen entré sí y estableciendo comunicación.
- **Versiones:**
	- IPv4 → Formato decimal punteado, 0-255 (*192.168.1.16*)
	- IPv6 → *ffff:ffff:ffff:ffff*
**Máscara de Subred:** Determina a que subred pertenece un dispositivo.
**Default Gateway:** Dirección IP del router que permite comunicarse con redes externas.
## Interfaces y Puertos

Cada interfaz física, tiene estándares o especificaciones que lo definen.
- **SVI:** Interfaz virtual de Switch
	- Permiten administrar remotamente un switch utilizando IPv4 o IPv6.
	- La SVI predeterminada es Interfaz VLAN1.
	- Un switch de capa 2 no necesita una dirección IP.
	- La dirección IP asignada al SVI se utiliza para acceder al swtich de forma remota.
