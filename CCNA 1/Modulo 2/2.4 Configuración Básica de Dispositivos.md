## Nombres de los Dispositivos

- Comenzar con una letra.
- No contener espacios.
- Finalizar con una letra o dígito.
- Utilizar únicamente letras, dígito y guiones.
- Tener menos de 64 caracteres de longitud.

```
Switch# configure terminal
Switch(config)# hostname SW
SW(config)#
```
## Pautas para Contraseñas

- Tener más de 8 caracteres de longitud.
- Combinación de letras mayúsculas, minúsculas, números, caracteres especiales.
- Evitar usar la misma contraseña para todos los dispositivos.
- No usar palabras comunes.
## Configuración de Contraseñas

### EXEC USUARIO

```
SW# configure terminal
SW(config)# line console 0
SW(config-line)# password cisco
SW(config-line)# login
SW(config-line)# end
SW#
```
### EXEC PRIVILEGIADO

```
SW# configure terminal
SW(config)# enable secret cisco01
SW(config)# exit
SW#
```
### LINEAS VTY (SSH-TELNET)

```
SW# configure terminal
SW(config)# line vty 0 15
SW(config-line)# password cisco
SW(config-line)# login
SW(config-line)# end
SW#
```
## Encriptación de Contraseñas

```
SW# configure terminal
SW(config)# service password-encryption
SW(config)#
```
## Mensaje de Aviso

```
SW# configure terminal
SW(config)# banner motd #MENSAJE DEL DÍA# 
```
