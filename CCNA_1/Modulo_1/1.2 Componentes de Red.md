## Roles de Host

**Host:** Dispositivo que está conectado y participa en la comunicación de una red.
- También son llamados Dispositivos Finales.
- Se logran identificar por la dirección IP, también permite la comunicación en la red.
- Roles: Cliente-Servidor
	- Cliente: Dispositivo que solicita información.
	- Servidor: Dispositivo que brinda información.
## Entre Pares

Arquitectura de red donde el host actúa como cliente/servidor en simultaneo.
## Dispositivos Finales

Dispositivo que es el origen o destino de un mensaje a través de la red.
## Dispositivos Intermediarios

- Conectan múltiples dispositivos finales a la red.
- Proporcionan conectividad y garantizan el flujo de datos en la red.
- Usan la dirección del host de destino.
## Medios de Red

Tipos de medios para interconectar dispositivos:
- **Cobre:** Los datos se codifican en impulsos eléctricos.
- **Fibra Óptica:** Los datos se codifican como pulsos de luz.
- **Transmisión Inalámbrica:** Los datos se codifican mediante ondas electromagnéticas.
